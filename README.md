**知乎批量拉黑工具**

- [介绍文章（发表于知乎）](https://www.zhihu.com/question/51803931/answer/2064387078666957794)

本项目提供一个油猴脚本，用于在知乎回答或文章页面上快速批量拉黑点赞者、答主粉丝，并支持自动跳过你的关注和粉丝名单，减少误伤。

## 脚本功能

- 批量拉黑回答/文章的点赞用户
- 批量拉黑回答/文章作者的粉丝
- 自动跳过你关注的人与你的粉丝
- 记录已拉黑用户并显示“已拉黑”标签

## 使用方式

1. 安装 Tampermonkey 或类似的油猴扩展。
2. 将 `zhihu-batch-block.user.js` 添加为用户脚本。
3. 打开知乎回答页或文章页。
4. 点击右下角悬浮按钮，选择“拉黑点赞者”或“拉黑答主粉丝”。

## 注意事项

- 该脚本仅在知乎页面上运行。
- 确保你已登录知乎，并允许脚本访问当前页面的请求。
- 使用前请确认理解批量拉黑的后果。
